# Treino

App simples para criar treinos, guardar o historico e registrar cargas para comparar com o treino anterior.

## Escopo inicial
- Criar e editar treinos e exercicios.
- Registrar execucoes e pesos usados.
- Consultar historico e comparar cargas.

## Estado
Repositorio inicial. Sem aplicacao implementada ou stack definida. Manter o escopo simples.
